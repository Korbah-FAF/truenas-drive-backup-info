Personal backup application

TrueNAS Drive Backup

An owner-operated tool for storing encrypted, versioned backups in the owner's Google Drive.

What the application does

The application runs on the owner's private server. It uses Backrest, restic and rclone to back up selected documents, photographs and application recovery files. Backup contents and file names are encrypted by restic before they are uploaded to Google Drive.

The owner uses a private Backrest interface to choose backup dates, browse saved folders and restore files. This website provides information about the application; it does not provide access to the backups or to the private server.

Google Drive access

The application requests the drive.file permission. This allows it to manage files and folders created or explicitly opened with this application, including its backup repository. It does not request access to Gmail, Google Photos or the rest of the owner's existing Drive files.

Only the owner's Google account is intended to authorise this application. There is no public registration or public backup service.

Privacy and contact

Read the privacy policy and terms of use. For questions, use the application's support email shown on its Google consent screen.
